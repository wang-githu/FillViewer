# FillViewer 3D 画面操作手册

> 面向现场操作与维护人员。目标是：**会用、能改、出问题能自己排查**。
> 全程只需要浏览器，不需要编程基础。

---

## 一、这套东西是什么

把 WinCC 里的实时数据，显示在一个可旋转、可缩放的 3D 工厂模型上：

- **设备变色**：阀门开/关、泵故障，模型上的设备立刻变绿/变红。
- **液位升降**：池子、仓里的液位，模型里的液面跟着涨落。
- **设备转动**：搅拌机、耙架按启停信号转或不转。
- **管道流动**：管子里有荧光粒子流动，快慢跟着流量走。
- **展板数值**：在设备旁边浮一块小牌子，显示料位/电流/频率等实时数值。
- **点击弹窗**：在 3D 里点设备，可以在 WinCC 里弹出对应的操作面板。

数据来源是 WinCC 自带的 REST 服务，**不写数据库、不改 PLC 程序**。

---

## 二、第一次使用：三步启动

1. 打开 `<安装目录>_发布` 文件夹（如果换了电脑，先解压部署包到任意目录）。
2. 双击 **`启动3D运行画面.cmd`**（只想改配置就双击 `启动3D配置台.cmd`）。
3. 浏览器会自动打开。没打开就手动访问：`http://127.0.0.1:8099/app/runtime.html`

> 绿色窗口（命令行）不要关，关掉服务就停了。

**常用的四个地址**

| 地址 | 用途 |
| --- | --- |
| `http://127.0.0.1:8099/app/studio.html` | 配置台（改绑定的地方，**只在配置时用**） |
| `http://127.0.0.1:8099/app/runtime.html?p=demo` | 运行画面（给操作工看的） |
| `http://127.0.0.1:8099/app/vardata.html` | 变量数据页（查变量、试写值） |
| `http://127.0.0.1:8099/index.html` | 旧版单页（一般不用） |

## 三、运行画面怎么用

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 旋转模型 |
| 滚轮 | 放大 / 缩小 |
| 右键拖动 | 平移 |
| 双击展板上的数值 | 弹出输入框，可以往 PLC 写值（**只有勾了"允许写入"的行才能写**） |
| 左上角红条 | 出故障了，红条上会写原因（变量取不到、模型没加载等） |

左上角正常情况下**只显示项目名**。看到任何红色提示，按第七节排查。

## 四、配置台：五个页签

配置台左上角选项目（一般就一个 `demo`）。右边五个页签，**每次改完一定要点顶部的「保存」**（橙色按钮），否则刷新就没了。

### 4.1 绑定页（让设备动起来）

一句话：**选设备 → 选动作类型 → 填变量 → 加到绑定**。

1. 左边列表点一个对象，或直接在 3D 里点设备（会高亮框住）。
2. 「类型」下拉选：

| 类型 | 用途 | 典型变量 |
| --- | --- | --- |
| 颜色（按状态/阈值） | 开=绿、关=红 | `..._DK1`（开到位）、`..._GB1`（关到位） |
| 状态规则（多变量） | 一条规则一个变量，可闪烁 | 多个开关量 |
| 颜色渐变 | 数值大小 → 红黄绿过渡 | 电流、开度百分比 |
| 缩放（按数值，纵向） | 液位涨落（从底部涨） | `..._PJ1`（料位/液位） |
| 旋转动画 | 连续转，可正反转、可选轴 | `..._PJ1`（频率/转速）+ 启停变量 |
| 数值 | 只读数字，不改变外观 | — |

3. 填「变量」——可以直接敲变量名，也可以从下拉里选；也允许直接填数字（如 `1000`）当固定值测试。
4. 点 **加到绑定**。下方「该对象的规则」会列出刚加的规则，可以「载入编辑」「删」。
5. 点顶部 **保存**。

> 小技巧：先点 **按名自动绑定**，程序会尝试按对象名去配对变量；配不上的会出现在「未匹配对象」，可以手动填变量名后点「绑」。

### 4.2 展板页（在设备旁边浮一块数值牌）

1. 点「在 3D 里点一下定位置」，然后到 3D 里点设备上的某处——坐标自动填好，并勾上「固定位置」。
2. 填「标题」（如 `灰仓`）、「宽度/字号」（留空=自动）。
3. 在「行」里点 **+ 增加一行**，每行填：标签（如 `料位`）、变量、单位、小数位；勾「千分位」显示 `1,234.5`。
4. 需要时勾该行的「允许写入」，这样运行画面里双击就能写值。
5. 点 **保存展板（并退出）**——保存会立刻写盘并退出编辑状态。

**拖动展板**：直接在 3D 里按住展板拖；按住 `Shift` 只上下移，按住 `Alt` 只前后移；靠近别的展板会自动对齐（出现虚线），`Ctrl` 用于 0.1 m 微调。

**显示控制**：给展板填一个「显示控制」变量，则该变量为 0 时展板显示、非 0 时隐藏（变量读不到时按「显示」处理，不会因为断线就消失）。

### 4.3 管道页（流动动画）

1. 左边列表里**直接点**一根根管子即可多选（再点一次取消；也支持 Ctrl/Shift）。
2. 点 **把选中的对象建成管线**。
3. 设「条件」（什么时候流动，如 `Demo_ZB1_YX1` 或 `Demo_AMDL1_BJ21 > 100`）、颜色、速度、间距、粒子数、拖尾长度。
4. 想按流量调速度：把「调速」填成流量变量，「满速值」填该变量的满量程。
5. 点管道卡片上的 **保存**，或顶部 **保存全部管线**。

喜欢的配色可以点 **存为模板**，以后在别的管道上「套用模板…」一键复制外观（不动对象和条件）。

### 4.4 全部页（体检）

「规则体检」会检查：绑定的对象是否存在于模型、变量是否存在于变量表、管线的对象名是否写错。

- **全部可用** = 没问题。
- 出现红色条目：右边有「删除」按钮；对象的还可以点候选名（蓝色的 `→ xxx`）一键换绑到正确对象。
- 改完点顶部 **保存**。

### 4.5 设置页

| 区块 | 作用 |
| --- | --- |
| REST 连接 | WinCC REST 地址，如 `https://主机名:8092/WinCCRestService`（**必须用主机名，不能用 IP**，证书问题） |
| 引擎光/画质 | 「画质」高/中/低，「背景」深色/浅色 |
| 运行选项 | 开机自启、启动后自动打开运行画面、全屏、默认项目/模型、生成 EXE（见第五节） |
| 刷新与延迟 | 轮询间隔（默认 300 ms）、服务端缓存（默认 200 ms）、强制直读 |
| 备份与回滚 | 每次保存前自动备份，可从历史版本一键回滚 |
| 单击回写 | 3D 里点设备时，把设备名写进 WinCC 变量，触发 WinCC 弹窗 |
| 变量表 | 导入 WinCC 导出的变量清单（`.txt` UTF-16 Tab 分隔，或自写 CSV） |

**刷新太慢怎么办**：变量变了画面不动，一般是这里太大。把「轮询间隔」调到 150–200 ms 试试；「强制直读」最实时但最吃 WinCC REST（它限流约 1000 次/10 秒，变量多时别开）。

## 五、运行选项与开机自启

设置页「运行选项」：

- **不自启**：手动双击启动（推荐先这样）。
- **用户登录后启动**：写一个快捷方式到当前用户的启动文件夹，**不需要管理员**，登录后自动开服务。
- **开机自启（计划任务 / SYSTEM）**：写 Windows 计划任务 `FillViewer服务`，跟用户是否登录无关，**需要管理员权限**。
  - 若保存时提示"创建失败（多半需要管理员）"，就去 `<安装目录>_发布\tools\` 右键 **以管理员身份运行** `启用服务级自启(需管理员).cmd`；要取消就跑 `关闭服务级自启(需管理员).cmd`。

**生成 EXE**：点「生成 / 重建 FillViewer.exe」，会在 `<安装目录>_发布\` 下生成 `FillViewer.exe`。双击它等于「启动服务 + 打开运行画面」一条龙，适合放到桌面或计划任务里。

- `FillViewer.exe -nobrowser`：只起服务、不开浏览器（服务级自启用这个）。

三个选项互斥：选了一种，会把另一种的自启方式清掉。

## 六、换了台电脑怎么部署

1. 把部署包 `FillViewer_部署包.zip` 解压到新机器的任意目录（路径别带空格更稳）。
2. 打开解压出来的 `config.json`，把 `restBase` 改成**新机器能访问到的 WinCC 主机名**：

```json
{
  "restBase": "https://desktop-xxxxxxx:8092/WinCCRestService",
  "restUser": "YOUR-WINCC-USER",
  "restPass": "YOUR-WINCC-PASSWORD"
}
```

3. 双击 `启动3D运行画面.cmd`。首次运行若提示缺 Python，就装上 Python 3.12（或把便携版 `python` 文件夹一起拷过去）。
4. 打开 `http://127.0.0.1:8099/api/live` 看是否返回数据；返回 `{"src":"rest"...}` 就成功了。

WinCC 那一侧还需要：**REST 服务已启动**（计算机属性 → 启动 → 勾 REST 服务），且**每个变量在变量属性里勾了 REST 读授权**。

## 七、常见问题（按现象查）

| 现象 | 原因与处理 |
| --- | --- |
| 改了配置，刷新还是旧样子 | 按 `Ctrl + F5` 强制刷新（浏览器缓存）。 |
| 左上角红条 `403 Forbidden` | WinCC 没给该变量开 REST **读**授权。到 WinCC 变量属性里勾上。 |
| 红条 `变量不存在` / `Not Found` | 变量名写错了，或该变量在 WinCC 里被删/改名。到「全部」页体检，点删除或换绑。 |
| 红条 `模型加载失败` | 模型文件名不对，或 `models\` 里没有这个文件。到设置页把「默认模型」选对。 |
| 参数改了模型一点不动 | ①顶「保存」了吗；②体检有红项吗；③点「测试」按钮看管线是否在跑；④把「刷新与延迟」调小。 |
| 双击数值写不进去 | 该行没勾「允许写入」，或 WinCC 侧该变量没开 REST **写**授权。 |
| 弹窗弹不出来 / 弹错设备 | WinCC 侧脚本问题：确认 `模型名称` 变量确实被写入了对象名，且脚本里的对比表里有这一行。 |
| 命令行一闪就退 | 端口 8099 被占用（上次的服务没关干净）。任务管理器结束 `python.exe` / `pythonw.exe`，再启动。 |
| 改代码后行为没变 | 服务是**旧的**还在跑。先结束 `python.exe`/`pythonw.exe`，确认 8099 没被占用，再启动。 |
| 浏览器打不开页面 | 服务没起来。看 `<安装目录>_发布\logs\server.log` 里的报错。 |

## 八、备份与回滚

- 每次点「保存」，服务端会先把上一版另存为 `*.bak_YYYYMMDD_HHMMSS`（每类保留最近若干份）。
- 设置页「备份与回滚」→ 选类别（绑定/展板/管线/看板模板）→ **列出备份** → 选一个时间点回滚。
- 误删、改错都能这样退回去。

**改任何东西的顺序**：改 → 点保存 → 到运行画面 Ctrl+F5 看效果。不生效先查"服务是否重启"和"浏览器是否强刷"。
